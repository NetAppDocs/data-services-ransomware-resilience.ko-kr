= NetApp Ransomware Resilience에서 차단 또는 허용된 파일 확장자 관리
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Ransomware Resilience는 의심스러운 파일 확장자를 차단하는 보호 전략을 구성할 수 있도록 지원합니다. Ransomware Resilience는 랜섬웨어 공격을 방지하기 위해 차단할 알려진 의심스러운 파일 확장자 목록을 기본적으로 제공합니다. 필요에 따라 항목을 추가하거나 제거하여 파일 확장자 목록을 사용자 지정할 수 있습니다.

의심스러운 파일 확장자 차단으로 보호를 구성하는 경우 워크로드 수준에서 설정됩니다. 하지만 스토리지 VM(SVM) 수준에서 파일 확장자를 사용자 지정할 수 있습니다. 즉, 동일한 워크로드 내의 서로 다른 SVM이 서로 다른 목록을 사용할 수 있습니다.



[[how-file-extension-blocking-works]]
== 파일 확장자 차단 작동 방식

파일 확장자 목록을 구성하는 방법에는 두 가지가 있습니다:

* *파일 확장자 차단* - 목록에 포함된 모든 파일 확장자는 차단되며 랜섬웨어 위협으로 표시됩니다.
* *파일 확장자 허용* - 이 목록에 있는 확장자를 가진 파일만 허용됩니다. 목록에 없는 확장자를 가진 파일은 차단되며 랜섬웨어 위협으로 간주됩니다.




[[file-extension-blocking-from-ontap]]
=== ONTAP에서의 파일 확장자 차단

ONTAP에서 특정 파일 확장자를 차단하도록 설정한 경우, Ransomware Resilience는 해당 설정을 인식합니다. Ransomware Resilience에서 의심스러운 파일 확장자를 차단하도록 link:rp-use-protect.html["보호 구성"]를 구성하는 경우, 다른 기본값을 구성하지 않는 한 Ransomware Resilience는 기본적으로 더 선별된 파일 확장자 목록을 사용하도록 전환됩니다.



[[default-file-extensions]]
=== 기본 파일 확장자

랜섬웨어 복원력은 "NetApp"이라는 차단된 파일 확장자 기본 목록을 제공합니다. 기본적으로 의심스러운 파일 확장자를 _차단_하도록 설정된 모든 워크로드는 3,900개 이상의 알려진 악성 파일 확장자가 포함된 이 목록을 사용합니다. 이 목록을 수정하거나 복사하여 사용자 지정 목록의 기반으로 사용할 수 있습니다.

다른 목록을 기본값으로 설정할 수 있습니다. 목록을 기본값으로 설정하면, 파일 차단이 활성화된 모든 워크로드는 수동으로 다른 목록을 선택하지 않는 한 해당 목록을 사용하게 됩니다.



[[create-a-file-extensions-list]]
== 파일 확장자 목록 생성

.단계
. 랜섬웨어 복원력에서 **설정**을 선택하세요.
. 파일 확장자 항목 아래에서 **관리**를 선택합니다.
. **추가**를 선택합니다.
. 목록에 사용할 *이름*을 입력하십시오.
. 목록이 작동하는 방식을 선택하세요:
+
** *확장자 차단*을 선택하면 목록에 있는 모든 파일 확장자가 랜섬웨어 위협으로 자동 표시됩니다.
** 목록에 있는 파일 확장자의 요청만 허용하려면 *확장자 허용*을 선택하십시오.


. 목록을 만드는 방법을 선택하세요:
+
** 기존 목록을 기반으로 작성하려면 *목록 복사* 탭을 선택하십시오.
+
파일 확장자 목록을 검토하십시오. 확장자를 삭제하려면 파일 확장자 유형 옆의 "X"를 선택하십시오. 추가 확장자를 추가하려면 *+ 목록에 추가*를 선택하십시오. 이 옵션을 선택하면 *수동으로 입력* 탭으로 이동합니다.

** CSV 파일에서 파일 확장자 목록을 추가하려면 *업로드* 탭을 선택하십시오.
+
*업로드*를 선택한 다음 차단하거나 허용할 파일 확장자 목록이 포함된 CSV 파일을 선택합니다.

** 목록을 직접 입력하려면 *수동 입력*을 선택하십시오. 목록은 쉼표로 구분된 값으로 입력하십시오(예: "vvv, xyz, zzz").


. 파일 확장자 목록을 검토한 다음 *추가*를 선택하여 새 목록을 만드십시오.
+
image:blocked-file-extensions.png["차단된 파일 확장자 스크린샷."]

[[svm]]
== SVM에 파일 확장자 목록 적용

의심스러운 파일 확장자 차단 정책이 포함된 랜섬웨어 보호 전략을 할당하면 전체 워크로드에 대해 특정 파일 확장자 목록을 지정할 수 있습니다. 보호 정책을 적용한 후에는 각 SVM에 서로 다른 목록을 적용할 수 있습니다.

이 작업을 수행하려면 의심스러운 파일 확장자를 차단하는 탐지 정책이 워크로드에 포함되어야 합니다. link:rp-use-protect.html["랜섬웨어 방어 전략을 구성합니다"] 방법을 알아보십시오. 각 SVM에는 하나의 파일 확장자 목록만 할당할 수 있습니다.

.단계
. 랜섬웨어 복원력에서 **설정**을 선택하세요.
. 파일 확장자 항목 아래에서 **관리**를 선택합니다.
. *스토리지 VM* 탭을 선택합니다.
. 의심스러운 파일 확장자 차단 보호 기능이 활성화된 SVM 목록을 검토하십시오. 어떤 SVM이 어떤 목록을 사용하는지 확인할 수 있습니다. 목록을 변경하려면 *목록 변경*을 선택하십시오.
. 대화 상자의 드롭다운 메뉴에서 새 목록을 선택한 다음 *저장*을 선택합니다.




[[manage-file-extension-lists]]
== 파일 확장자 목록 관리

파일 확장자 목록의 내용은 언제든지 수정할 수 있습니다. 목록을 삭제하거나, 의심스러운 파일 차단 기능을 활성화했을 때 기본값으로 사용할 목록을 변경할 수도 있습니다.

.파일 확장자 목록 수정
. 랜섬웨어 복원력에서 **설정**을 선택하세요.
. 파일 확장자 항목 아래에서 **관리**를 선택합니다.
. 수정하려는 파일 확장자 목록을 확인하세요.
. 파일 확장자를 목록에 추가하려면 작업 메뉴를 선택한 다음 *파일 확장자 추가*를 선택하십시오.
+
.. 목록을 수정하는 데 사용할 방법에 해당하는 탭을 선택하십시오. 기존 목록을 가져오려면 *목록 복사*를 선택하고, CSV 파일에서 파일 확장자를 가져오려면 *업로드*를 선택하고, 파일 확장자를 수동으로 입력하려면 *수동 입력*을 선택하십시오.
.. 변경 사항을 저장하려면 *추가*를 선택하세요.


. 파일 확장자를 제거하려면 파일 확장자 메뉴에서 수정하려는 목록의 이름을 선택하십시오.
+
.. 파일 확장자 목록에서 제거하려는 각 파일 확장자 옆의 확인란을 선택합니다. 목록 맨 위에서 **제거**를 선택합니다.
+
또는 제거하려는 개별 파일 확장자의 행 끝에 있는 작업 메뉴를 선택한 다음 *제거*를 선택합니다.



. 목록을 수정하려면 *저장*을 선택하십시오.


.파일 확장자 목록을 기본값으로 설정합니다
. 랜섬웨어 복원력에서 **설정**을 선택하세요.
. 파일 확장자 항목 아래에서 **관리**를 선택합니다.
. 기본값으로 설정하려는 목록의 작업 메뉴를 선택한 다음 *기본 목록으로 표시*를 클릭합니다.
. 그런 다음 해당 목록은 기본값으로 태그가 지정됩니다. 특정 목록으로 표시되지 않은 차단된 파일 확장자 목록으로 보호되는 워크로드는 새 기본값에 따라 파일 확장자를 차단하거나 허용합니다.


.파일 확장자 목록 삭제
SVM에 적용된 리스트는 삭제할 수 없습니다. 먼저 <<svm,SVM과 관련된 목록을 변경합니다>>해야 합니다.

NetApp 목록은 삭제할 수 없습니다.

. 랜섬웨어 복원력에서 **설정**을 선택하세요.
. 파일 확장자 항목 아래에서 **관리**를 선택합니다.
. 삭제하려는 목록의 작업 메뉴를 선택한 다음 *목록 삭제*를 선택합니다.
. 대화 상자에서 삭제를 확인하십시오.

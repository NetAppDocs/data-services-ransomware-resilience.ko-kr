[[enhanced-isolated-recovery-environment-configuration]]
=== 향상된 격리 복구 환경 구성

Ransomware Resilience는 이제 향상된 격리 복구 환경 구성 워크플로를 제공합니다. 새로운 워크플로는 클라우드 또는 온프레미스 환경을 위한 격리 복구 환경 설정 프로세스를 명확히 하고 간소화합니다.

자세한 내용은 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-clean-restore.html["정상적인 복원을 위해 격리된 복구 환경을 구축합니다."^]을 참조하십시오.



[[enhanced-workflow-for-enabling-user-activity-monitoring]]
=== 사용자 활동 모니터링을 활성화하기 위한 향상된 워크플로

Ransomware Resilience는 사용자 활동 모니터링 활성화 워크플로를 개선했습니다. 이전에는 Ransomware Resilience가 워크로드에서 사용자 활동 모니터링을 사용하는 랜섬웨어 보호 전략을 활성화할 때마다 데이터 수집기의 연결을 테스트했습니다. 이번 업데이트를 통해 스토리지 VM에 데이터 수집기가 존재하고 "실행 중" 상태인 경우 해당 확인 단계를 건너뛰어 보호 워크플로 속도를 향상시켰습니다.

자세한 내용은 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/rp-use-protect.html["워크로드 보호"^] 참조하십시오.



[[google-cloud-netapp-volumes-flex-service-level-generally-available]]
=== Google Cloud NetApp Volumes Flex 서비스 레벨이 일반 출시되었습니다.

Google Cloud NetApp Volumes의 Flex 서비스 레벨에 대한 랜섬웨어 복원력 지원이 이제 정식 출시(GA)되었습니다.

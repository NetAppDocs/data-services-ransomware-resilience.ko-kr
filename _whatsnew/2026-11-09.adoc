[[managed-blocked-file-extensions]]
=== 관리되는 차단된 파일 확장자

Ransomware Resilience는 이제 *의심스러운 파일 확장자 차단* 보호 옵션을 활성화한 경우 워크로드에서 허용 또는 차단되는 파일 확장자 목록을 사용자 지정할 수 있는 기능을 제공합니다. 이 개선 사항을 통해 스토리지 VM(SVM)에서 특정 파일 형식만 허용하거나 특정 파일 확장자를 차단하도록 워크로드를 구성할 수 있습니다. 이 개선 사항은 파일 확장자 옵션에 대한 더욱 세밀한 제어를 지원하며, 각 SVM마다 다른 목록을 생성할 수도 있습니다.

자세한 내용은 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-file-extensions.html["Ransomware Resilience에서 차단된 파일 확장자 관리"]을 참조하십시오.

=== 사용자 활동 에이전트 생성을 위한 새로운 수동 워크플로

Ransomware Resilience는 이제 수동 사용자 활동 에이전트 생성 워크플로를 제공하여 VM에서 사용자 활동 에이전트를 생성하는 방법을 더욱 세밀하게 제어할 수 있도록 합니다. 이 새로운 워크플로를 사용하면 VM SSH 키를 제공하지 않고도 사용자 활동 에이전트를 직접 설치하고 프록시 설정을 구성할 수 있습니다.

자세한 내용은 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/suspicious-user-activity.html#create-a-user-activity-agent["사용자 활동 에이전트를 생성합니다"^]을(를) 참조하십시오.

이미 NetApp Data Infrastructure Insights(DII) Workload Security를 사용 중인 경우, 동일한 Workload Security 에이전트를 NetApp Ransomware Resilience에도 사용할 수 있습니다. NetApp Ransomware Resilience를 위해 별도의 Workload Security 에이전트를 배포할 필요는 없습니다. 단, 동일한 Workload Security 에이전트를 사용하려면 NetApp Ransomware Resilience Console 조직과 DII Storage Workload Security 테넌트 간의 페어링 관계가 필요합니다. 이 페어링을 활성화하려면 담당 영업 담당자에게 문의하십시오.

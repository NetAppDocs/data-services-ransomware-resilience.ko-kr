의심스러운 파일 확장자 차단 옵션은 조직에 대해 구성한 기본 목록을 사용합니다. 생성한 link:task-file-extensions.html["사용자 지정 목록을 사용하세요"]을(를) 보려면 연필 아이콘을 선택하십시오.

+ ONTAP에서 차단된 파일 확장자 목록을 구성한 경우, *ONTAP 목록을 랜섬웨어 복원력 목록으로 대체*를 선택하여 해당 목록을 재정의할 수 있습니다. 그런 다음 SVM에서 *차단된 목록을 제외한 모든 파일 확장자 허용* 또는 *허용된 목록을 제외한 모든 파일 확장자 차단* 중 하나를 선택합니다. 그런 다음 드롭다운 메뉴에서 목록을 선택합니다. 워크로드의 모든 스토리지 VM(SVM)은 해당 목록을 사용하며, 나중에 워크로드의 다른 SVM에 다른 목록을 적용할 수 있습니다.

백업 및 복구와 랜섬웨어 복원력을 모두 사용하는 경우, 두 제품으로 보호되는 공통 데이터는 랜섬웨어 복원력에 의해서만 청구됩니다.

워크로드가 보호됨으로 분류되면 구매한 용량 또는 종량제 구독에 포함됩니다.  Ransomware Resilience는 암호화 또는 사용자 활동 감지 정책이 활성화된 경우 워크로드를 보호됨으로 분류합니다.  이러한 감지 정책 중 하나라도 없으면 워크로드는 위험으로 분류됩니다.  위험 워크로드는 구매한 용량에 포함되지 않습니다.

보호 대상 워크로드는 무료 평가 기간 종료 후 구매 용량 또는 구독료에 포함됩니다. Ransomware Resilience는 효율성 적용 전, 보호 대상 워크로드와 관련된 데이터(ONTAP에서 보고된 데이터 기준)를 GB 단위로 청구됩니다.

규모 산정 시 라이선스 비용은 데이터가 핫 스토리지 또는 콜드 스토리지 계층에 있는지 여부와 관계없이 액티브 파일 시스템의 논리적 용량을 기준으로 합니다. 스냅샷이 콜드 스토리지 계층에 저장되더라도 스냅샷에 사용되는 공간은 이 계산에 포함되지 않습니다.
